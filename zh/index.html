上海SHANGHAI · TOP 10

中国的经济与文化心脏，东西方文明在此交汇。外滩的万国建筑群与陆家嘴的现代天际线隔江相望，石库门里弄与摩天大楼共存，是中国国际化程度最高的城市之一。

+
外滩万国建筑博览群，浦江两岸的城市名片 +

外滩位于黄浦江西岸，全长约1.5公里，拥有52幢风格各异的古典复兴建筑，被誉为"万国建筑博览群"。与对岸陆家嘴天际线隔江相望，日夜皆景，是上海最具标志性的景观带。

推荐搭配：上海三甲医院国际医疗部就诊 + 浦江夜景疗愈漫步

豫园 · 城隍庙明代江南园林与城市烟火气的完美结合 +

豫园始建于明代，是上海现存唯一的古典园林，曲径回廊、假山池沼精巧玲珑。园外城隍庙商圈老字号云集，是体验上海传统民俗与美食的绝佳去处。

推荐搭配：体检后半日轻松行程，园林漫步有助身心放松

东方明珠广播电视塔矗立浦东的上海地标，360° 俯瞰全城 +

东方明珠高468米，曾是中国第一高塔。塔内设有观光层、悬空观光廊与历史陈列馆，登塔可360度俯瞰黄浦江两岸全景，是认识上海的第一站。

推荐搭配：眼科 / 耳鼻喉术后恢复期的轻体力游览项目

上海博物馆中国古代艺术殿堂，青铜与陶瓷的重镇 +

上海博物馆收藏青铜、陶瓷、书画、玉器等文物逾百万件，被誉为"中国文物半壁江山"。其建筑造型寓意"天圆地方"，本身就是一件艺术品。

推荐搭配：候诊间隙的室内文化行程，全年皆宜

田子坊石库门里的艺术街区，老上海的文艺缩影 +

田子坊由老式石库门里弄改造而成，窄巷纵横间遍布画廊、工作室、咖啡馆与特色小店，是体验上海创意文化与市井气息的热门街区。

推荐搭配：口腔诊疗复诊间隙的短距离步行游览

南京路步行街中华商业第一街，购物与霓虹的盛宴 +

南京路是上海最繁华的商业街，被誉为"中华商业第一街"。沿街老字号与旗舰店林立，入夜后霓虹璀璨，适合轻松步行游览。

推荐搭配：术后康复期平缓步行线路（可乘坐观光小火车代步）

新天地石库门新生的时尚地标 +

新天地保留并改造了成片石库门建筑，将老上海风情与现代餐饮、时尚品牌融为一体，是感受上海夜生活与海派文化的必到之处。

推荐搭配：商务合作洽谈与晚宴接待的理想场所

武康路历史文化街区梧桐深处，百年建筑露天博物馆 +

武康路全长仅1.1公里，却汇集了37处历史建筑，包括著名的武康大楼。梧桐掩映下的西班牙式、法式花园住宅，构成一座"露天建筑博物馆"。

推荐搭配：低强度 City Walk，适合体检后的午后漫步

上海中心大厦中国第一高楼，云端之上的城市之巅 +

上海中心高632米，为中国第一、世界第三高楼。位于118层的观光厅"上海之巅"可俯瞰全城，超高速电梯55秒直达，是体验现代中国工程奇迹的窗口。

推荐搭配：身体状况良好者的城市观光项目，感受中国速度

朱家角古镇上海威尼斯，江南水乡的千年记忆 +

朱家角已有1700多年历史，36座古桥横跨漕港河，放生桥为沪上最大石拱桥。乘摇橹船穿行水巷，可尽赏典型的江南水乡风情。

推荐搭配：周末一日水乡疗养游，远离都市喧嚣

浙江ZHEJIANG · TOP 10

江南水乡的代表，数字经济高地。从杭州西湖的诗意到乌镇的水乡韵味，从普陀山的佛国净土到雁荡山的奇峰飞瀑，山水与人文在这里完美融合。

+
杭州西湖人间天堂，世界文化遗产 +

西湖以"淡妆浓抹总相宜"的诗意闻名天下，2011年被列入《世界遗产名录》。苏堤春晓、断桥残雪等"西湖十景"四季流转，环湖漫步、泛舟湖上皆是享受。

推荐搭配：高端体检 + 西湖养生漫步的经典组合

灵隐寺 · 飞来峰千年古刹，江南禅宗圣地 +

灵隐寺始建于东晋，距今1700余年，为江南著名古刹。寺内飞来峰造像群为宋元石刻精华，古木参天、环境清幽，是静心养性的绝佳去处。

推荐搭配：中医 Wellness 调理 + 禅修静心体验

乌镇中国最后的枕水人家，世界互联网大会永久会址 +

乌镇完整保存了晚清和民国时期的水乡古镇格局，十字形的内河水系将全镇分为四栅。白墙黛瓦、乌篷摇曳，被誉为"中国最后的枕水人家"。

推荐搭配：术后康养旅居，枕水而眠的慢生活体验

西塘古镇生活着的千年古镇，廊棚与石桥的画卷 +

西塘已有千年历史，以"桥多、弄多、廊棚多"著称。千米烟雨长廊沿河而建，雨天不湿鞋、夏季不暴晒，是江南水乡原生态生活的活样本。

推荐搭配：摄影爱好者与疗休养客人的理想目的地

普陀山海天佛国，观音菩萨道场 +

普陀山是中国四大佛教名山之一，素有"海天佛国"之称。岛上寺院林立、梵音缭绕，金沙碧海与古刹奇礁相映，既是朝圣地，也是海滨疗养胜地。

推荐搭配：心灵疗愈之旅 + 海滨空气疗养

千岛湖天下第一秀水，1078 座岛屿的湖泊奇观 +

千岛湖因新安江水电站蓄水而成，湖中有1078个岛屿，水质为国家一级水体。环湖骑行、游艇观光、品尝鱼头美食，是自然康养的热门目的地。

推荐搭配：术后森林氧吧康复计划

雁荡山东南第一山，世界地质公园 +

雁荡山形成于一亿二千万年前的火山喷发，以奇峰、瀑布、洞穴著称。灵峰夜景、大龙湫瀑布为"雁荡三绝"之最，被誉为"东南第一山"。

推荐搭配：骨科康复期适宜的低海拔登山线路（须遵医嘱）

莫干山江南第一山，避暑胜地与民宿之乡 +

莫干山以"竹、云、泉"三胜闻名，清末即为中外人士的避暑胜地。山上200余幢近代别墅风格各异，如今精品民宿云集，是高端山居康养的发源地。

推荐搭配：中医调理 + 山居避暑的高端康养套餐

横店影视城东方好莱坞，穿越千年的影视主题乐园 +

横店影视城是全球规模最大的影视拍摄基地，拥有明清宫苑、秦王宫、清明上河图等十余个跨越千年的影视场景，可亲身感受中国影视工业的恢宏。

推荐搭配：随行家属的娱乐行程，患者安心静养

钱塘江大潮天下第一潮，大自然的壮丽奇观 +

钱塘江大潮被誉为"天下第一潮"，每年农历八月十八前后最为壮观，一线潮、交叉潮、回头潮气势磅礴，自古即为天下奇观。

推荐搭配：秋季就医客户的限定自然景观体验

云南YUNNAN · TOP 10

中国民族文化最多彩的省份，素有"植物王国"与"动物王国"之称。雪山、湖泊、梯田、雨林与古城交织，四季如春的气候使其成为康养旅居的理想之地。

+
丽江古城东方威尼斯，纳西文化活态遗产 +

丽江古城始建于宋末元初，是中国保存最完整的少数民族古城之一，1997年被列入《世界遗产名录》。四方街、小桥流水与纳西古乐，构成雪山脚下的慢时光。

推荐搭配：高原气候康养（海拔约2400米，请遵医嘱）

玉龙雪山纳西神山，北半球最南的大雪山 +

玉龙雪山13座雪峰终年积雪，主峰扇子陡海拔5596米。山脚下的蓝月谷湖水湛蓝如镜，冰川公园索道可直达4506米观景平台，近距离感受雪山雄姿。

推荐搭配：心肺功能良好者的雪山观光（须经医疗评估）

大理洱海风花雪月，高原明珠 +

洱海形如人耳，是云南第二大高原湖泊。环湖自驾、骑行或乘船游湖，可观苍山洱海"风花雪月"四景，白族村落与网红打卡地沿岸散布。

推荐搭配：术后环湖轻度骑行康复线路

石林天下第一奇观，喀斯特地貌博物馆 +

石林形成于2.7亿年前，是世界上喀斯特地貌的典型代表，2007年列入世界自然遗产。奇石如林、千姿百态，被誉为"天下第一奇观"。

推荐搭配：昆明就医客户的半日地质奇观游

普达措国家公园香格里拉秘境，中国大陆首个国家公园 +

普达措位于香格里拉，拥有明镜般的高山湖泊、原始森林与草甸湿地，春夏杜鹃漫山、秋冬层林尽染，是离天堂最近的秘境之一。

推荐搭配：身心疗愈 + 高原森林浴（海拔3500米以上，请遵医嘱）

泸沽湖高原明珠，摩梭人的母亲湖 +

泸沽湖海拔2690米，湖水能见度达12米，被誉为"高原明珠"。湖畔摩梭人保留着独特的母系氏族文化，猪槽船、走婚桥与星空木屋别具风情。

推荐搭配：静心疗养 + 少数民族文化体验

崇圣寺三塔大理地标，千年佛都的见证 +

崇圣寺三塔始建于南诏时期，主塔千寻塔高69.13米，是中国现存最高的古塔之一。三塔倒影公园中"塔影倒映"的景象堪称大理第一胜景。

推荐搭配：大理康养线路中的文化静心站点

元阳梯田大地的雕刻，哈尼族千年农耕奇观 +

元阳梯田由哈尼族历经1300年开垦而成，2013年被列入世界遗产。灌水期的梯田如镜面层层叠叠，日出日落时分光影变幻，被摄影师誉为"大地雕塑"。

推荐搭配：冬季康养摄影专线

西双版纳热带雨林王国，傣乡风情 +

西双版纳是中国唯一的热带雨林自然保护区，拥有望天树空中走廊、野象谷等独特景观。傣族泼水节、傣味美食与热带风情，使其成为冬季避寒康养的胜地。

推荐搭配：冬季避寒 + 中医"冬病夏治"调理之旅

虎跳峡万里长江第一峡，世界级徒步圣地 +

虎跳峡以"险"名天下，金沙江在玉龙雪山与哈巴雪山之间奔腾而下，峡谷垂直落差3900米，为世界最深峡谷之一，亦是国际知名的徒步路线。

推荐搭配：仅限健康条件允许者的轻徒步体验（须专业评估）
